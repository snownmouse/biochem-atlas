- 日期：2026-11-05

- 方式：真实渲染（`vite preview` + Edge headless + playwright-core），1440×900 与 1280×900 各跑一遍；只读探查，未改任何源码、未提交

## 0. 一句话结论

**最致命的是「看不出能点」：25 个被检查页面里有 23 页中招，共 493 处可点目标在静止态没有任何视觉提示；挂图上 291 处步骤/节点/表行只靠 `cursor: pointer` 暗示，11 张挂图里 10 张的画布内没有任何键盘可达目标（glycogen 虽有 39 个焦点，但焦点样式是浏览器默认 5px 框）。** 这不是"再加一句引导"能解决的，需要把"可点"变成挂图本身的一种视觉语法。

## 1. 方法与口径

### 1.1 测量方式

1. 用 `playwright-core` 启动 Edge（`channel: "msedge"`），在 `http://localhost:4173`（`npm run build` 后的 `vite preview`）逐页加载。
2. 页面内用统一选择器收集可点目标：`a[href] / button / input[type=checkbox] / [role=button] / [role=tab] / g[data-step-id] / g[data-node-id] / g[data-module-id] / g[data-prep-id] / g[data-transport-id] / .home-node / .home-edge / g[data-cori-loop] / .j-item / .dn-seg / .aside-toggle / .frames-entry / tr[style*=cursor]`。
3. 逐个目标取 `getComputedStyle`，判定"静止态可见提示"= 有下划线 / 有可见边框 / 有背景色块；都没有即记为**静默目标（silent）**。原生 checkbox 的系统外观不计入静默（结构页原始计数 8 处中含 6 个 checkbox，本报告按 2 处真静默计）。
4. 另测：出路口文案与位置、首屏引导语、`<title>` 悬停信息数、Tab 焦点序列与 focus 样式、3D 画布/提示/复位按钮。
5. 交互探针：真实 hover、真实 click、真实 Tab，记录 URL、右栏内容、hover 前后 `stroke-width`、焦点外框。

### 1.2 计数单位

- **处** = 一个可点目标，或一个"本应有却没有"的控件。同一目标只计一次。
- 结构页每个区块的分子对照不做逐原子计数；3D 画布按"可见 canvas"计。

补充实测：
- **hover 探针**：糖酵解步骤箭头 hover 前后 `stroke-width` 均为 `1.6px`，无任何视觉变化；唯一反馈是光标变手。
- **focus 探针**：glycogen 是唯一画布可 Tab 的挂图，第一个节点在第 17 站，焦点框为浏览器默认 `5px auto`（与全站 1px 砖红规范不一致）；其余 10 张挂图画布 0 个焦点。
- **3D**：结构页「重置视角」按钮 0 个；单步页有 1 个（y≈367）。
- **1280**：所有页面 `scrollWidth == 1280`，无页面级横向溢出；计数与 1440 完全一致，只是挂图画布内部横向滚动比例更高，点击目标更易被裁到视口外（未计入静默数）。
- **首屏引导语命中**：总图 1/1；挂图 8/11（glycolysis、tca、gn、ppp、fao、fas、cori、urea）；oxphos 仅「DETAIL · 点击带上模块/节点」；glycogen、amino 无；结构页 0/10；单步页 3D 提示 1/1（但不含"上一步/下一步在哪"）。

### 4.2 交互探针的原始结论

- 糖酵解：点击步骤 → `?step=gk-1`，右栏详情顶在 y=307（首屏可见）；点击节点（该节点属已选步）→ URL 退回 `/pathway/glycolysis`，**步骤被取消选中**，界面无任何"取消"提示。
- 首页：hover 共用节点时圆填充 `none → rgba(156,74,60,.12)`；点击共用节点 → `selectedJunction=f6p` 写入右栏，但 `#home-aside` 处于 `hidden`（默认收起），**首屏看不到任何变化**；点击通路标题直接跳到 `/pathway/glycolysis`（无中间态、无去向提示）。
- 结构页：模式切换真实写 URL（`?mode=2d`），反馈成立；`← 返回挂图` 的 href 固定为 `/pathway/glycolysis?step=gk-1`，从 gk-7 进入再返回会落到 gk-1。
- 键盘：糖酵解 Tab 16 站即回绕（12 导航 + 3 器官 tab + 自测），画布 0 站；结构页 23 站（导航 + 模式 + 6 筛选）；首页需 29 站才到第一个共用节点。

## 6. 改进方案

### 6.1 全局导航：总图 ↔ 挂图 ↔ 结构对照

#### 方案 A（推荐）：顶部"三停"导航檐 + 常驻返回/上下张

- **放什么**：一条 36px 高的页头导航（不吸顶时紧随现有 masthead 上方；吸顶时用 `position: sticky; top: 0` + 1px 墨线底边，不用阴影）。
- **放哪**：左侧 `总图 / 糖酵解 / 结构对照` 三停面包屑（当前停 700 字重 + 2px 墨线；其余 12px 灰字 + 点线下划线）；右侧 `← 上一条` `下一条 →`（11px）、`结构对照 ↗`、`← 回总图`。
- **形态**：纯文字 + 1px 直角线，无卡片/圆角/底色；当前停用 2px 下压线，非当前用点线，完全复用 `PathwaySwitcher` 已有语法。
- **视觉代价**：36px 垂直空间；吸顶时遮住挂图顶部约 36px，可用 `scroll-margin-top` 让 plate 让位。
- **与纸白/墨线冲突**：无。新增元素全部是既有语法的复用。
- **收益**：D 类 24 处、C 类 20 处可一次解决；键盘 ←/→ 可顺手接入。

#### 方案 B：左侧 PLATE 00–11 竖向索引条

- **放什么**：`position: sticky` 左缘 44px 竖条，竖排 `00…11` 数字；当前项加粗 + 2px 左竖线；hover 时右侧浮出通路名（1px 边框的纸白方块）。
- **视觉代价**：每页常驻 44px 宽；1440 下挂图左内边距只有 28px，需要重排；1280 下画布再窄 44px。
- **冲突**：与 PLATE 编号体系同源，风格兼容；但与首页已有的"整张地图"重复，且首页不需要索引条。
- **适合**：二期做"全站地图"时再考虑，不建议现在上。

#### 方案 C：零常驻 chrome，只加页脚一行 + 键盘快捷键

- **放什么**：挂图页脚报脚行 `← 总图 · 上一条：TCA · 下一条：糖异生 →`；结构页底部同款一行。
- **视觉代价**：近零；但只在页面底部，滚动中不可见，触屏用户需要滑到底。
- **冲突**：无。
- **适合**：作为 A 的补充（键盘 `Alt+←/→` 换通路、`←/→` 换步），不作为主方案。

**建议**：落地 A（顶部三停檐 + 常驻返回/上下张）+ C 的键盘快捷键；B 留作二期全站地图。A 的重点不是"再加一层导航"，而是把现有 `PathwaySwitcher` 的 12 项压缩成"三停 + 上下张"，让用户随时知道"我在哪一层、下一步能去哪"。

### 6.2 可点性表达：统一三态（与 1px 直角图框兼容）

> 约束：不圆角、不投影、不渐变、四色封顶。以下全部用 1px 线 + 9.2–11px 字。

**默认态（静止）——让"可点"成为图的一种语法**

1. **文字目标**（步骤酶名、节点名、表行首列、器官 tab、模式按钮）：
   - 加 1px 点线下划线（SVG 用 `<line stroke-dasharray="1 2">`，落字下方 2px；HTML 用 `border-bottom: 1px dotted rgba(34,40,42,.35)`）。
   - 理由：点线下划线在全站已经是"链接"的既有语义（`PathwaySwitcher`、`frames-entry`、`d-pdb-id`），零学习成本。
2. **箭头/连线目标**（步骤箭头、首页 61 条边）：
   - 箭头起点加 4px 直角"折角"（两条 1px 短线，不填充），或在中点加 3px 竖向 tick；不额外描边、不加光环。
3. **节点目标**（圆/胶囊）：在圆外 3px 处加 1px 虚线圆环（`opacity:.35`），仅可点节点有；不可点节点没有。
4. **图例补一行**：挂在 plate-head 右端（与现有 9.2px 图例同排）：
   `点线/折角 = 可点 · 悬停出「→ 去向」· 点击看详情`
5. **总开关**：plate-head 右端增加 `显示可点线索 ●开` 文本按钮（1px 边框、方角），默认开；关掉后回到现在的纯净海报态。这样既解决可发现性，也不牺牲挂图的干净。

**hover 态**

- 线宽 1px→2px（墨色），节点虚线环 `opacity:.35→.7`；
- 指针旁固定偏移出"去向浮签"：纸白底、1px 墨边框、方角、11px、无阴影，内容如
  - 步骤：`第 3 步 · PFK-1 → 右栏详情`
  - 首页连线：`PGK · gk-7 → 糖酵解 gk-7`
  - 首页共用节点：`共用节点 · 接通 3 条通路 → 右栏详情`
- 浮签用 HTML 层（`position: fixed`，跟随指针），不放进 SVG，避免改变画布布局。

**focus 态**

- 1px 砖红 `outline-offset: 2px`（与 `.organ-tab`、`.ps-link` 一致）；SVG 目标用同款矩形框；
- `role="button"` + `tabindex=0` + Enter/Space 触发；
- 浮签同 hover，保证键盘用户也能看到去向。

**为什么不用"hover 才亮"**：用户的问题是"找不到键"，hover 只对已经摸到目标的人有效；默认态必须有标记。触点用户没有 hover，默认态标记是唯一解法。

### 6.4 触屏替代（hover 信息必须另有出路）

1. **首页共用节点**：点击 = 选中 + 右栏**自动展开**（`setAsideOpen(true)`）；同时节点旁 200ms 内出现 1px 边框的浮签「共用节点 · 已选中，详情见右栏」。若用户不想展开右栏，则改为底部 1px 顶线的固定条，显示节点名 + 「查看详情 ↑」。
2. **首页连线/通路标题**：单击 = 选中并显示底部固定条 `PGK · gk-7 → 进入糖酵解 gk-7`，条上「进入 →」再单击才换页（避免误触直接跳走）。这是"触屏版 hover"。
3. **挂图步骤/节点**：单击仍然直接选中（详情在首屏右栏，已有反馈）；同时给被点中的目标 2px 砖红下压线，保证"点到了"可见。
4. **结构页 `title=` 等级说明**：把 13–18 条 hover-only 说明改为**常驻 9.2px 注释行**（放在等级标签下方），不再用 `title=`；若必须保留，则加同文案的「说明 ⓘ」按钮，点击展开 1px 边框面板。
5. **3D**：结构页提示文案补全触屏版本：`拖动旋转 · 双指缩放 · 点残基高亮 · 重置视角`；reset 按钮常驻，误操作可回。
6. **长按替代**：不推荐把长按作为唯一入口（与浏览器菜单冲突），只在空间极度受限的浮签上使用。
