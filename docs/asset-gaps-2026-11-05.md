## 0. 口径

- **现状分类**：`none`（只有文字，2D / 3D 都没有）/ 有 2D 无 3D / 有 3D / 只有计算构象。
- **缺什么**：分别指出 2D 结构式、3D 坐标两项。
- **难度**：低 = 分子小、实验配体好找；中 = 带电 / 多原子或组合底物；中高 = 无小分子实验配体，只能计算构象；高 = 长链 / 大分子片段或本酶口袋确实不存在。
- **红线**：不用类似物冒充真底物；`experimental` 才允许写 PDB ID / 分辨率 / 物种 / 链 / resname；RDKit 生成一律 `computed`，页面显示「计算构象」；本酶口袋未命中时保留 `none` 或明确标注跨蛋白来源，不静默替换。

## 7. 冲突清单（发现但未改既有通路化学数据）

1. **`fas-er` 产物 part 的 id 与分子式不一致**：原配置用 `{ ...FAS_C4_OH, id: "fas-c4-acyl" }`，id 写「酰基」但分子式仍是羟酰的 C₄H₇O₂S，而块级产物公式为 C₄H₇OS（饱和酰基）。本轮改为 `FAS_C4_ACYL`（C₄H₇OS），与块级公式一致；未改动数据层步骤本身。
2. **`fas-te` 底物 part 用了棕榈酸的分子式**：原配置底物为 `FAS_C16`（C₁₆H₃₁O₂⁻），而块级底物公式写的是棕榈酰-ACP 的 C₁₆H₃₁OS。本轮拆出 `FAS_C16_ACYL`（C₁₆H₃₁OS）作为底物，`FAS_C16` 只作产物。
3. **丙二酰-CoA 的实验来源蛋白不是 FASN，也不是 ACC**：8H6C 的 MLC 来自人 GCN5；页面按 `other + human` 标 C，未冒充本酶。
4. **棕榈酸来源 2WUT 是人髓鞘蛋白 P2（脂肪酸结合蛋白）**：不是 FASN，页面按 `other + human` 标 C，并写明本酶口袋未获。
5. **尿素来源 1HQG 是大鼠 ARG1 H141C 突变体**：非人源 + 突变体，页面按 B 级中性记录，未按人源野生型处理。
6. **乙酰-CoA 分块口径与 TCA 页不同**：TCA 页既有资产 `accoa` 的分子式为 C₃H₆OS（含 CoA 折线起点碳），FAS 块级公式为 C₂H₃OS（只含乙酰基 + 硫酯 S）。两处片段边界不同，故 FAS 单独建 `fas-accoa`，不直接复用 TCA 资产；两者都不冒充完整乙酰-CoA（C₂₃H₃₆N₇O₁₇P₃S）。
7. **`docs` 中未发现既有缺口登记文件**：本轮按实测盘账结果为准；PPP / FAO「未建」的旧说法与实测不符（两通路资产均已齐备），已在 §1 修正。
