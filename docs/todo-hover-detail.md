  3. 时序：hover **280ms** 弹出、移出 **220ms** 关闭、触屏长按 **450ms**；键盘 focus 120ms 弹出。
  4. 关闭：`Esc` / 固定态点空白 / 滚动 / resize / 路由变化；固定态滚动同样关闭。
  5. 触屏长按出完整气泡，取代旧「→ 步骤详情」浮签；无模型时降级回旧浮签。
  6. 无障碍：focus 弹气泡、`aria-describedby` 指向气泡内容、`Esc` 关且焦点留目标、414 个目标 Tab 顺序不变。
  7. 总开关关闭后气泡一并失效，回静态图逐像素等同。
- **验收口径（2026-11-06 定稿）**：遮挡自身目标 0 px²（硬）、压图框内正文 0 px²（硬）、气泡 ≤5% 视口（硬）、气泡落在图框内的部分均为非文本区（软，取代原 12,000 px² 绝对上限）。

## 需确认的问题（登记时，2026-11-06 已逐条拍板，见上「结论」）

1. **交互形式**（三选一或组合）
   - `tooltip`：跟随指针的小浮层，只读、不遮挡图面；适合短句，不适合长解释。
   - 侧栏：固定在右侧阅读栏联动显示（类似现有挂图右栏详情），不遮图、可容纳长文与能量账。
   - 浮层：点击/悬停后在图上弹出卡片，空间大但会遮挡邻近节点，需要定位与关闭策略。
2. **触发方式与延迟**
   - 触发对象：通路标题 / 节点圆 / 步骤箭头 / 注记文字，哪几类？
   - 触发条件：`mouseenter` 立即弹，还是 `hover` 停留 200–500ms 后再弹（防误触）？
   - 关闭条件：移出即关 / 点击空白关 / Esc 关。
   - 触屏没有 hover：是否改为"点按一次显示，再点关闭"。
3. **内容深度**
   - 只重复图上已有文字（等于无信息），还是补充酶全名、能量账、调控、临床意义？
   - 内容来源必须是数据层（`skeleton.json` / 各通路 `*.json`），不得在组件里手写第二份文案。
4. **与"后面几步"的联动**
   - 用户提到该需求可能与后续"后面几步"（分步阅读 / 逐步高亮 / 步骤详情）相关；hover 详情可能只是分步阅读的低成本前置。
   - 若后续要做"点一步、右侧详情跟着走"，hover 浮层与点击选中应该共用同一套详情渲染，避免两套文案。
   - 需确认：hover 只做"预览"，点击才"锁定"？两者是否共用 `?step=` 状态？
5. **无障碍与性能**
   - 键盘 `focus` 是否也弹出（`tabindex` / 屏幕阅读器朗读）。
   - 首页元素数量大，是否只对节点与标题绑定，避免全量监听。

## 实现前的验收草案（待用户确认后细化）

- 不改首页现有上下两域与七条通路标题的版式；浮层不得把标题挤出首屏。
- 不新增缩放；滚动仍用原生滚动条。
- 浮层文字全部来自数据层 JSON，缺失字段时报"数据缺口"，不伪造。
- 新增冒烟：hover 后出现详情、移出后消失、键盘可达、无控制台报错。
