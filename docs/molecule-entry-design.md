# 物质简介条目设计说明

> 用途：记录“物质气泡 + 独立简介页”这一版内容骨架的设计依据，供后续把 5 个样板铺到其余 74 个时复用。
>
> 来源说明：本文依据公开可查的教材目录、章节提要与样章结构做**间接核对**，未逐页核对教材全文；文中引用的书名、版次、章号只用于定位知识范围，**不是教材原文**。页面与气泡中的所有事实，要么能回到项目数据层字段，要么能回到教材的章级知识点；不写页码，不写真题年份。

## 1. 为什么要改骨架

上一版四段（角色 / 位置 / 来源去路 / 为什么在这）是按“通路位置”组织的，回答的是“它在这条链里干什么”，不是“它是什么”。用户的原始判断是：生物化学教材第一部分先讲生物分子，顺序是“这是哪一类物质 → 结构上有什么关键特征 → 有什么理化性质 → 因此在生命体系里承担什么基本角色”，然后才讲它出现在哪些代谢环节。

这一版进一步按国内教材的小节写法收紧：

- 人卫版《生物化学》的小节标题多用判断句，而不是“这是什么 / 什么性质”这类名词短语。
- 王镜岩《生物化学》第 11 章把“维生素本体 + 辅酶形式”成对讲（维生素 B1 与 TPP、泛酸与辅酶 A、叶酸与四氢叶酸）。所以辅酶类条目必须交代维生素来源，否则条目不完整。
- 受众是学医 / 学生物的，不是化学系。不写构象分析、键长键角、轨道、pKa 精确值；只写与细胞行为有关的带电状态、溶解性、稳定性、反应性基团。

## 2. 新骨架

每条按以下顺序展开：

1. **判断句小标题**：先立论，例如「G6P 是糖代谢的分岔点」「乙酰-CoA 是两碳单元的通用货币」。
2. **分类归属**：一句话说清它属于哪一类（糖磷酸酯 / α-酮酸 / 硫酯 / 氨基酸 / 含氮小分子），不展开理化性质。
3. **在链上的位置**：哪条通路、第几步、哪个酶催化，一到两句。
4. **生成与去路**：从什么来、变成什么去、分几个方向，用动词链写实。
5. **生理或临床落点**：为什么细胞在乎它，能挂到具体现象就挂。
6. **考点与易错**：一小块，考唯一性、位置、数字、易错点。

**删除「什么性质」整段**：溶解性、带电状态只在直接影响细胞行为时顺带一句。**不再单列「基本角色」与「在通路里」**：它们与 3、4、5 重复，合并进位置、生成去路和生理落点。

辅酶 / 维生素类另加一条：写清维生素本体与辅酶形式的关系。乙酰-CoA 条目因此写明“由泛酸（维生素 B5）构成的辅酶 A，与乙酸形成硫酯，活性形式是酰基-CoA 硫酯”。

## 3. 页面与气泡

### 简介页 `/molecule/:id`

- 顶部：面包屑 + 「返回上一页」。
- 头部：判断句主标题、分类归属、别名。
- 左栏四个板块（标题均为判断句）：
  1. 在链上的位置（含挂图深链）
  2. 生成与去路
  3. 生理 / 临床落点
  4. 考点与易错
- 右栏：结构特征（有 3D 资产就嵌现有查看器；没有就留文字说明）、教材与数据出处。
- 页脚再给「返回首页 / 返回上一页」，未知 id 页给出 5 个样板入口，避免死胡同。

### 气泡

- 容量不变：260×158，21 个全角字/行，最多 5 行；样板只放两行正文 + 一行入口。
- 第一行写“它是什么类的东西”，第二行写“它在链上的关键作用”，不写性质。
- 例：
  - G6P：`糖磷酸酯，葡萄糖的胞内形式` / `糖酵解、PPP 与糖原的交汇点`
  - 丙酮酸：`α-酮酸，三碳的糖酵解终产物` / `决定碳进线粒体还是变乳酸`
  - 乙酰-CoA：`泛酸构成的辅酶 A 硫酯，两碳载体` / `TCA 第 1 步底物，也是脂合成起点`
  - 丝氨酸：`含羟基的中性氨基酸，一碳单位原料` / `脱氨进丙酮酸，也能供磷脂`
  - 尿素：`含氮小分子，两个氮的载体` / `把氨装成中性分子运到肾`

## 5. 边界

- 不改导读、3D 资产、首页画布、`package.json`、锁文件。
- 不改任何既有气泡容量与交互；样板气泡只换两行文案并保留「→ 物质简介」入口。
- 不写页码、不写真题年份；没有数据层或章级出处的说法不写。
