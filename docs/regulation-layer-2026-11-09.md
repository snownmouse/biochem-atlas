## 0. 结论先行

这五张图的调控层，真正能落到具体步骤上的只有三类：**终产物或辅因子的变构反馈**（MTHFR ← SAM、SAH → 甲基转移酶、CPS2 ← UTP、PPAT ← AMP/GMP/IMP、IMPDH ← GMP、RNR ← dATP）、**药物靶点**（TS ← 5-FU、DHFR ← 甲氨蝶呤、DHODH ← 来氟米特、IMPDH ← 霉酚酸、RNR ← 羟基脲）、以及**脂蛋白图的受体—转录轴**（SREBP-2 → LDLR、LXR → ABCA1、PCSK9 → LDLR 降解）。最缺的是三块：其一，一碳单位、嘧啶、嘌呤三张图的「激素层」几乎是空的——教材级证据里没有胰岛素 / 胰高血糖素 / 糖皮质激素直接磷酸化这些酶的可靠描述，强行画箭头会造出假机制；其二，甘油磷脂图的「转录层」缺 SREBP-1c / ChREBP → GPAT / lipin 与 ORMDL → SPT 这两段，鞘脂侧尤其只有蛋白—蛋白调控而没有转录调控；其三，五张图共用的画外节点（DHFR 叶酸循环、胆固醇合成、嘌呤分解、补救途径、心磷脂 CLS）在图上没有位置，而一半以上的药理断点恰恰打在这些节点上，制图时必须用「画外框 + 虚线」显式标注，否则药物会挂在错误的步骤上。

## 1. PLATE 14 · 一碳单位代谢（oc-1 – oc-9）

现状判断：这张图的调控层集中在「SAM / SAH 比值」与「叶酸—B12 营养状态」两个变量上，酶本身的变构调节只有 MTHFR 一条是教材级明确的；激素层与转录层都很薄，不建议在图上补画激素箭头。
