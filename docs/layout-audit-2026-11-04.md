## 四、统一图框（一处定义，各页引用）

`src/styles.css` 内单一规则块：

```css
.poster {
  --plate-frame-ink: #22282a;   /* 墨色细边框 */
  --plate-frame-paper: #f6f3ec;/* 纸白底 */
  --plate-frame-pad: 24px;     /* 图与框之间的冗余内边距 */
}
.poster .plate-scroll {
  border: 1px solid var(--plate-frame-ink);  /* 1px 直角，无圆角/投影/渐变 */
  background: var(--plate-frame-paper);
  padding: var(--plate-frame-pad);
  margin: 8px 12px 18px;                     /* 框外呼吸间距 */
}
```

派生（同一套变量，不复制颜色/尺寸）：

- 3D 电泳/酶面板：`.e3d-stage`、`.e3d-host { inset: var(--plate-frame-pad) }`
- 结构对照 3D 分子：`.mol3d-stage`、`.mol3d-host { inset: var(--plate-frame-pad) }`
- 结构对照 2D 结构式：`.mol2d-svg { inset: var(--plate-frame-pad); width/height: calc(100% - 2*var(--plate-frame-pad)) }`
- 单步页 3D 主位：`.poster.step-poster .s-figure`（边框 + padding），WASD/滚轮提示用 `calc()` 贴内边距

审计实测：38 页全部图框四边 `1px`、四边 `padding: 24px`（`smoke-layout` 逐页断言）。

## 五、重叠判定与排除规则（smoke 沿用同一套）

1. **不跨系统**：SVG `<text>` 只在同一 `<svg>` 内两两比较（`getBoundingClientRect`）；HTML 文本用 `Range.getClientRects()` 取真实字形框；SVG 与 HTML 不互比。
2. **同组设计性叠放不计**：节点缩写文字与节点圆本身无文字框相交，天然不进入计数；父子嵌套的 HTML 文本跳过。
3. **行高外扩排除**：CJK 文本包围盒高度 > 字号（line-height 1.25~1.6），相邻两行即使字形不压，包围盒也会探入。判为"行内叠放"（`excluded`）的条件是：
   - 两文本中心距 `dy > 4px`，且
   - 纵向探入 `< 45%` 较小文本高度。
   其余（同基线、深度相交）即"有效重叠"，必须为 0。
4. 相交面积阈值 `> 2px × 2px` 才记录，过滤抗锯齿边缘的 1px 贴合。
5. 每条记录输出 `system / rect / overlap / significant / excluded / reason`，可逐条复核。
