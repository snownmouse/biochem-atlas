# 氧化磷酸化（OxPhos）内容骨架（outline）

定位：TCA 与脂肪酸氧化产出的 NADH/FADH₂ 的最终兑现站。本文只做内容骨架 + 3D 适配性判断。

## 电子传递链（复合体 I–IV）
- **复合体 I**（NADH:泛醌氧化还原酶）：NADH + Q + 5H⁺(基质侧) → NAD⁺ + QH₂ + 4H⁺(膜间隙)。哺乳动物约 45 个亚基、约 1 MDa；FMN 与 8–9 个 Fe-S 簇接力电子，L 形（臂+膜臂）。Q位点在臂与膜臂交界。
- **复合体 II**（琥珀酸脱氢酶，见 tca/outline）：FADH₂ → Q，**不泵质子**（电子入口低于 NADH，能量不足以泵 4H⁺）。
- **复合体 III**（细胞色素 bc₁）：QH₂ + 2 cyt c(Fe³⁺) + 2H⁺(基质) → Q + 2 cyt c(Fe²⁺) + 4H⁺(膜间隙)。**Q 循环**（Q cycle）：两个 QH₂ 分两轮氧化，经由双 Q 位点（Qo/Qi）实现每 2e⁻ 泵 4H⁺；Rieske [2Fe-2S]、cyt b（bL/bH）、cyt c₁。
- **复合体 IV**（细胞色素 c 氧化酶）：4 cyt c(Fe²⁺) + O₂ + 8H⁺(基质) → 4 cyt c(Fe³⁺) + 2H₂O + 4H⁺(泵出)。含 CuA、血红素 a/a₃ 与 CuB 双核中心；O₂ 的 4e⁻ 还原一步完成防 ROS 外泄。
- **ATP 合酶**（复合体 V，F₁F₀）：F₀ c-环旋转质子发动机（哺乳动物 c8 环，每环 8H⁺），γ 轴带动 F₁ 三 β 亚基按 Binding Change 机制循环"开放-松弛-紧绷"，每 120° 释放 1 ATP → 8H⁺/3ATP ≈ **2.67 H⁺/ATP**。另有寡霉素敏感蛋白 OSCP 与 ATP-ADP 转位酶、磷酸载体协同。

## 化学渗透（Mitchell 理论）
质子动力势 Δp = Δψ（膜电位，主要贡献 ~150–180 mV）+ ΔpH（小贡献 ~0.5）。内膜对 H⁺、OH⁻ 不透，能量以电化学梯度存储。解偶联剂（2,4-DNP、产热脂肪的 UCP1）打漏梯度 → 电子传递照跑、ATP 归零、以热散失——教学上"能量账必须过质子"的证伪实验。

## P/O 比与"质子数/ATP"：现代共识与争议
- 教材老值：NADH = 3 ATP、FADH₂ = 2 ATP（1960s 实测整除值，已过时但考题仍在）。
- 现代共识值：NADH ≈ 2.5、FADH₂ ≈ 1.5。推导：NADH 共泵 10H⁺（4+0+4+2），ATP 合成消耗 ~2.67 H⁺ + 转位酶 ~1 H⁺/ATP ≈ 3.67 → 10/3.67 ≈ 2.7，工程上取 2.5；琥珀酸 6/3.67 ≈ 1.6，取 1.5。
- 争议点（要写进"未核实/争议"栏）：① H⁺/ATP 精确值随 c-环大小（人 c8、酵母 c10、大肠杆菌 c14）与 ANT 漏电而变，不存在唯一整数；② 各复合体泵质子化学计量（尤其复合体 I 的 4H⁺）在活细胞中受"滑行"（slip）与质子回漏影响，体内实测 P/O 波动大（Watt 等 2010 综述）；③ UCP 生理性解偶联的程度与产热贡献，教材与运动生理学界口径不一。

## 与 TCA 的接驳
NADH（基质，PDH/TCA/β-氧化产）直接进复合体 I；胞质 NADH（糖酵解第 6 步）经苹果酸-天冬氨酸穿梭（肝/心，等价 2.5 ATP）或甘油-3-磷酸穿梭（肌/脑，折损为 FADH₂ 级 1.5 ATP）间接进链——**这是糖酵解档案 gk-06 的直接后续**。FADH₂ 只能从复合体 II/ETF 进（少 1 次 4H⁺）。

## 3D 适配性总判断
- 适合 3D（实验结构成熟、结合姿态明确）：复合体 III（牛/鸡 bc₁ 双 Q 位点与 Rieske 头部摆动双态，条目未核实）、复合体 IV（牛 Cox，O₂/CO/CN⁻ 配体结构多）、ATP 合酶 F₁ 部分（核苷酸三种占据态的经典结构）+ c-环（晶体结构多物种均有）。这三件是"明星结构"候选。
- 只能 2D：Q 循环完整两轮流程（动态无全结构捕获）；复合体 I 全景（1 MDa 超预算，且质子泵机制无"结合姿态"可言）；化学渗透总图；滑行/回漏等争议机制。
- 硬约束提醒："只展示实验结构可支撑的结合姿态"意味着：质子泵的动力学机制（D-通道、质子中继网络）只能文字+2D 示意，3D 只能摆结构上真实存在的配体与辅因子。复合体 I 若一定要 3D，建议只做截取视图并显著标注"片段化展示"。
