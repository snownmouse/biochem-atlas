# 戊糖磷酸通路（Pentose Phosphate Pathway, PPP）内容底稿

> 体例对齐 glycolysis/gk-04.md，压缩为 8 节。PDB 条目已于 2026-11-03 经 RCSB API（GraphQL + search API + chemcomp 化学字典）实时核验。与既有档案的衔接点：gk-02 significance 已写明"G6P 本身就是戊糖磷酸通路的入口，在 C1 位与此通路分流"——本档案是该句的展开。

## 1. 反应式（两相总览）

**氧化相（不可逆，产还原力）：**
G6P + 2 NADP⁺ + H₂O → 核酮糖-5-磷酸（Ru5P）+ CO₂ + 2 NADPH + 2 H⁺

三步：① G6PD 脱氢（G6P → 6-磷酸葡糖酸-δ-内酯，NADP⁺→NADPH）；② 6-磷酸葡糖酸内酯酶 6PGL 水解开环；③ 6-磷酸葡糖酸脱氢酶 6PGD 氧化脱羧（→ Ru5P，第二个 NADPH，CO₂ 从 C1 释放）。

**非氧化相（可逆，碳骨架重新洗牌）：**
3 Ru5P → 2 F6P + 1 GAP（2 × 转酮醇酶 TK + 1 × 转醛醇酶 TA，另经 Ru5P 3-差向酶 RPE 与核糖-5-磷酸异构酶 RPIA 在 Ru5P↔R5P 间换手）。

**净账（6 分子 G6P 循环，Lehninger Ch.14 可追溯）：**
6 G6P + 12 NADP⁺ + 7 H₂O → 5 G6P + 6 CO₂ + 12 NADPH + 12 H⁺ + Pi
——"6 进 5 出"：烧掉一个 G6P 换 12 NADPH，其余碳全部回炉。

## 3. 热力学与 ΔG

- 氧化相三步**生理不可逆**（G6PD 步强放能，CO₂ 释放 + 内酯水解共同拉动）；逐步 ΔG°′ 数值 Lehninger Ch.14 未列成表（与糖酵解 Table 15-1 不同），本档案**不编数**，页面只做"可逆/不可逆"标注。
- 非氧化相全部近平衡可逆——流向由下游需求决定（要 NADPH 时反向拼回糖酵解中间体，要 R5P 时正向出核糖）。
- 氧化相与糖酵解竞争同一 G6P 池：G6PD 拼不过 PFK-1 时（NADP⁺ 被耗尽时）就断流——NADP⁺/NADPH 比值是氧化相的节流阀（教材共识，定性）。

## 4. 辅因子与化学计量

- NADP⁺ ×2（氧化相唯一电子受体；结构上有"结构性 NADP⁺"稳定二聚体的报道，未核实精确表述）。
- TK：TPP + Mg²⁺（与 PDH/丙酮酸脱羧酶共享辅胺化学）。
- TA：活性 Lys 席夫碱（无辅因子）。
- RPE：Fe²⁺ 或 Zn²⁺（人源晶体中见 Fe²⁺，见下表 3OVQ/3OVP）。
- 化学计量锚点：1 G6P → 2 NADPH + 1 CO₂（氧化相）；6 G6P → 12 NADPH（循环净账）。

## 5. 调控与生理意义

- G6PD 是限速+调控点：底物 G6P 浓度、NADP⁺/NADPH 比值驱动；NADPH 竞争性抑制（产物抑制，定性）。
- **G6P 是分流点**：G6P 三选一——糖酵解（PFK-1）、糖原合成、PPP（G6PD）；胰岛素上调 G6PD 表达（合成脂肪需要 NADPH，长期调控）。
- 红细胞中约 5–10% 的 G6P 流入 PPP（教材口径有出入，未核实唯一数，页面写"约十分之一"级别即可）——红细胞唯一的 NADPH 来源，撑起谷胱甘肽还原系统对抗氧化。
- NADPH 四大去向：脂肪酸/胆固醇合成、谷胱甘肽还原（抗氧化）、NADPH 氧化酶（免疫爆发）、细胞色素 P450。
- 与糖酵解的双向接口：非氧化相可逆，使"全部碳走氧化相"成为可能（6 循环净账）——这是"旁路不是支路，是并联电路"的教学点。

## 6. 常见教学误解（3 条）

1. "PPP 是糖酵解的支路/废物处理"——它是并联产能模式，氧化相产还原力而非 ATP；6 G6P 净账里 5 个 G6P 完整回炉，碳不浪费。
2. "NADPH 和 NADH 差不多"——专一性刻在酶的结合口袋里：G6PD 拒收 NAD⁺，GAPDH 拒收 NADP⁺；氧化力用途不同（分解代谢 vs 合成+抗氧化）。7SNI 全酶结构里 NADP⁺ 的 2′-磷酸基看得见。
3. "CO₂ 从 C6 释放"——氧化相脱羧掉的是 G6P 的 **C1**（6PGD 步），与糖酵解（C1/C6 在丙酮酸上才分）不同；这与 gk-02 档案"G6P 在 C1 位分流"一句严格对应。

## 7. 临床关联

- **G6PD 缺乏症**：X 连锁，全球最常见的酶缺陷病（>4 亿人）：氧化应激药物（伯氨喹、磺胺）、蚕豆（favism）诱发急性溶血（OMIM 305900）。教学联动：与 gk-3 的 Tarui 病、gk-6 红系 NADH 去向同属红细胞性格题。
- **TALDO（转醛醇酶）缺乏**：罕见，肝硬化样表型 + 白内障 + 心肌病（OMIM 606003，未核实细节）。
- **RPIA 缺乏**：罕见神经发育障碍（OMIM 608611，未核实）。
- 癌症代谢：6PGD/TKTL1 在肿瘤中上调（关联确定，机制叙述需谨慎）。

**3D 四格适配判断：**

- **G6PD（7SNI）**：帧带首选。底物态（NAP+BG6）一帧讲两个故事；apo 帧缺——所有 G6PD 结构都带结构性 NADP⁺ 或配体，人源 apo 未检索到 → 缺格声明（先例：gk-1 F1 帧）。 cryo-EM 2.5 Å 对"看 2′-磷酸基"这个教学点够用。
- **RPE（3OVQ + 3OVP）**：全 PPP 唯一人源"apo + 真底物"两帧齐的酶，金属（Fe²⁺）口袋故事完整，第二顺位上。
- **转酮醇酶（4KXV）**：0.97 Å 的 TPP + 拟底物，单帧静态展示价值极高；但 TK/TA 的教学重点是"搬几碳基团、两两接力"，本质是图逻辑——**3D 单帧 + 2D 接力图**组合，不做四格。
- **6PGL / RPIA**：人源无结构，双缺口。选项：A) 用细菌/利什曼替代并标注（平台已有同工酶跨物种先例）；B) 纯 2D 示意。建议 O2/N1 两步走 2D，不硬凑。

**与糖酵解数据的冲突检查（不自行改 glycolysis.json）：**

1. **无直接数据冲突**。gk-02 significance 的"G6P 是 PPP 入口、C1 分流"与本档案核验结论一致（CO₂ 确从 C1 释放）。
2. **衔接注意**：非氧化相产物 F6P/GAP 要回流糖酵解，平台通路图若并网，gk-2/gk-4/gk-5 三个节点需要新增"PPP 来向"入边；skeleton.json 坐标未预留，届时需扩骨架（此处仅立项，不动代码）。

**上这条通路的最小可行范围**：只上 **G6PD（7SNI 单帧）+ RPE（3OVQ/3OVP 双帧）** 两个 3D 结构，加上氧化相/非氧化相各一张 2D 示意图（含 6 循环净账），就能讲清"分流点 G6P、NADPH 专属、C1 脱羧、碳回炉"四个核心点。必须先解决的缺口：人 6PGL 与 RPIA 无结构——接受替代源标注或纯 2D，二选一；G6PD 人源 apo 缺格需沿用"声明式缺口"体例。
