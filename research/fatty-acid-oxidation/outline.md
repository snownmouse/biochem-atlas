# 脂肪酸 β-氧化（Fatty Acid β-Oxidation）内容底稿

> 体例对齐 glycolysis/gk-04.md，压缩为 8 节。范围限定：**线粒体基质内的脂肪酸 β-氧化分解**（活化 → 肉碱穿梭 → 四步循环），不碰脂肪酸合成（两条通路化学互补但酶系完全不同，将来另立档案）。PDB 条目已于 2026-11-03 经 RCSB API（GraphQL + search API + chemcomp 化学字典）实时核验。

## 1. 反应式

**活化（ER/线粒体外膜）：**
脂肪酸 + CoA-SH + ATP → 脂酰-CoA + AMP + 2 Pi（焦磷酸随后水解，总代价 **2 个高能磷酸键**——"ATP→AMP+2Pi"是活化步的教学锚点）

**转运（肉碱穿梭）：**
CPT1（外膜，限速）把脂酰基转给肉碱 → 脂酰肉碱经 CAT（转位酶）入基质 → CPT2（内膜内侧）换回 CoA-SH。肉碱 = β-羟-γ-三甲氨基丁酸；长链脂肪酸（C14+）必须走此门，中短链可直接扩散入基质。

**四步循环（每轮削去两个碳）：**
以 C16 棕榈酰-CoA 跑 7 轮（Lehninger Ch.17 净式，可追溯）：
棕榈酰-CoA + 7 FAD + 7 NAD⁺ + 7 CoA-SH + 7 H₂O → 8 乙酰-CoA + 7 FADH₂ + 7 NADH + 7 H⁺

| 轮内步 | 反应 | 酶（人） | EC |
|---|---|---|---|
| β1 | 脱氢：脂酰-CoA → 反式-Δ²-烯酰-CoA，FAD→FADH₂ | 酰基-CoA 脱氢酶（ACAD，链长分工：VLCAD/LCAD/MCAD/SCAD） | 1.3.8.7 等 |
| β2 | 水化：反式双键加水 → L-3-羟脂酰-CoA | 烯酰-CoA 水合酶（ECHS1，crotonase） | 4.2.1.17 |
| β3 | 再脱氢：L-3-羟 → 3-酮脂酰-CoA，NAD⁺→NADH | 3-羟酰-CoA 脱氢酶（HADH/SCHAD；长链底物由三功能蛋白 MTP 兼任） | 1.1.1.35 |
| β4 | 硫解：C3–C4 断键 + CoA-SH 进攻 → 乙酰-CoA + 短两个碳的脂酰-CoA | β-酮脂酰-CoA 硫解酶（ACAA2） | 2.3.1.16 |

β1 与 β3 的氧化剂**刻意不同**（FAD vs NAD⁺）：β1 产物的烯酰-CoA 双键太"低能"只能给 FAD（得 1.5 ATP 当量），β3 产物的羟基是标准醇氧化，够格还原 NAD⁺（2.5 当量）——"氧化剂分级"是本通路第二教学锚点。

## 2. 酶与 EC（补充要点）

- ACAD 家族：FAD 共价/非共价结合视成员而定（MCAD 为 FAD 非共价）；电子经 ETF（电子传递黄素蛋白）→ ETF-QO 送入呼吸链——与 oxphos 档案的电子入口衔接。
- MTP（线粒体三功能蛋白）：β2+β3+长链 β1 复合在一条多肽上；教学主线用可溶四酶（MCAD/ECHS1/HADH/ACAA2），MTP 作组织分布补充。
- 硫解酶化学：Cys 硫酯中间体，与糖酵解"高能键转移"对比——这是平台里第一次出现 **CoA 硫酯 + 亲核催化的 Claisen 断键**。
- 奇数碳脂肪酸：最后一轮产丙酰-CoA → 走丙酰-CoA 羧化支路入 TCA（本切片只留一句注记，不展开）。

## 3. 热力学与 ΔG

- **总账（Lehninger Table 17-1，可追溯）**：1 分子棕榈酸彻底氧化 = 8 乙酰-CoA × 10 + 7 FADH₂ × 1.5 + 7 NADH × 2.5 = 108，减活化 2 = **净 106 ATP**（现代 P/O 口径 2.5/1.5）。老教材 129（P/O 3/2）口径差异必须在页面 note 并存——与 oxphos 档案 P/O 纪律一致。
- 四步循环中 β1–β3 近平衡；β4 硫解强放能（把反应拉向断裂），具体 ΔG°′ 数值 Lehninger 未单列，**不编数**。
- 对比钩子：葡萄糖 6C 氧化净 ~30–32 ATP（约 5 ATP/碳）；棕榈酸 16C 净 106（约 6.6 ATP/碳）且几乎无水携带——"为什么储能选脂肪"的数字答案。

## 4. 辅因子与化学计量

- FAD（β1）、NAD⁺（β3）、CoA-SH（活化 + β4）、H₂O（β2）。
- 每轮净产出：1 FADH₂ + 1 NADH + 1 乙酰-CoA（任务书口径）。
- 肉碱穿梭不耗能（CAT 电中性交换），但长链脂肪酸的"入场券"被 CPT1 的丙二酰-CoA 抑制所管控（见 §5）。

## 5. 调控与生理意义

- **CPT1 是限速闸**：丙二酰-CoA（脂肪酸合成第一步的产物）抑制 CPT1——"合成开启时把分解的门焊死"，避免无效循环（教材共识）。
- 激素：胰高血糖素/肾上腺素 → PKA → 脂肪组织脂肪酶磷酸化 → 脂肪酸动员↑；胰岛素反向。肝内脂解与 β-氧化能力联动。
- 酮体衔接：肝 β-氧化过载时乙酰-CoA 走酮体生成（长期饥饿/未控制糖尿病）；本切片仅一句注记，将来另立。
- 生理意义：空腹供能主力（心、静息肌优先烧脂肪）、高能密度（9 kcal/g 的代谢学解释）。

## 6. 常见教学误解（3 条）

1. "活化那 2 个 ATP 从总账里忘了扣/或扣了 4 个"——ATP→AMP+2Pi 等于 2 个高能磷酸键，总账净 106 已扣 2；写"消耗 2 ATP"和"ATP 变 AMP"两种表述要一致。
2. "四步循环每轮产 3 个 NADH/FADH₂"——**每轮只有 1 NADH + 1 FADH₂**；FAD 在前 NAD⁺ 在后，顺序不能倒（FAD 对应双键生成步）。
3. "β-氧化直接产 ATP"——循环本身只产还原当量与乙酰-CoA，ATP 全部在呼吸链兑现；把 β-氧化画成"产 ATP 的循环"是最常见图错。

## 7. 临床关联

- **MCAD 缺乏**：最常见脂肪酸氧化缺陷，婴幼儿空腹诱发低血糖 + 低酮体性昏迷（OMIM 201450）；新生儿筛查覆盖。
- **VLCAD 缺乏**（OMIM 201475）、**LCHAD/MTP 缺乏**（OMIM 600890，与母亲 HELLP 综合征关联，未核实细节）。
- **CPT1A/CPT2 缺乏**：CPT2 成人型为运动诱发肌红蛋白尿（OMIM 255110）；CPT1A 缺乏为空腹低血糖（OMIM 255120）。
- **原发性肉碱缺乏**（OCTN2/SLC22A5 转运体，OMIM 212140）：肉碱补充有效——"转运体也是通路一部分"的活例子。
- 教学联动：与糖酵解 gk-6（红系还原当量去向）、oxphos（FADH₂ 电子入口在 ETF-QO，绕过复合体 I）三处形成"电子从哪进呼吸链"专题。

**3D 四格适配判断：**

- **主线帧带可行度全场最高**：β1（1EGC 底物态 / 4P13 近 apo）、β2（2HW5 底物态 / 1HZD apo）、β3（1F0Y NAD+底物双配体）、β4（4C2J CoA 态）——四个酶全部有人源结构且三个带真底物/辅酶，"同一条 C4/C8 碳链走四扇门"的叙事成立。
- **链长统一缺口**：1EGC 的 MCAD 底物是 C8（CO8），β2/β3/β4 结构是 C4（COO/CAA）——帧带若要"同一分子贯穿四格"需跨结构刚体对齐（沿用 gk-1 F3 帧 G6P 对齐管线先例）并标注"链长差异：MCAD 用 C8 展示"。
- **肉碱穿梭**：CPT1 人源无结构（膜蛋白）→ 穿梭段走 2D 示意；CPT2 可用鼠 2RCU（棕榈酰肉碱类似物在位）做一张单帧，标注跨物种。
- **活化步**：3EQ6 是人源酰基-CoA+AMP 同框，单帧价值高；注意它是中链 ACS（ACSM2A）不是长链 ACSVL——页面标注同工酶差异。

**与糖酵解/既有数据的冲突检查（不自行改 glycolysis.json）：**

1. 无直接冲突。缩写纪律：本档案全程用"乙酰-CoA / 脂酰-CoA"，不出现 G3P；甘油骨架（甘油-3-磷酸）属脂解切片，不在本档案范围，避免与 gk-05 的"G3P = 甘油醛-3-磷酸"混淆点交叉。
2. 能量账衔接：本档案"乙酰-CoA × 10 ATP"直接引用 TCA 档案的 Lehninger Table 16-x/TCA 循环产出（10 ATP/乙酰-CoA，现代口径）——两份档案的 P/O 口径（2.5/1.5）必须同版本；research/index.md 中 oxphos 行的"P/O 争议已单列"即为此事。
3. 前瞻提示：糖酵解 gk-6 产 NADH（胞质），本通路产 NADH（基质）——若未来做"NADH 去向"总图，两处来源的穿梭机制（苹果酸-天冬氨酸 vs α-磷酸甘油）不同，页面需分列（仅立项，不视为冲突）。

**上这条通路的最小可行范围**：只上 **β1–β4 四个酶各一帧（1EGC、2HW5、1F0Y、4C2J）+ 活化步 3EQ6 单帧**，配一张四步循环 2D 图和 106-ATP 能量账，就能讲清"活化 2 键 → 穿梭 → 每轮 1 FADH₂ + 1 NADH + 1 乙酰-CoA → 7 轮 106 ATP"。必须先解决的缺口：① 链长统一（C8 vs C4 跨结构对齐 + 标注）；② CPT1 无结构——穿梭段降级 2D；③ 3EQ6 的 ACSM2A 中链同工酶归属标注。
