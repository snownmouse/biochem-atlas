# 糖异生（Gluconeogenesis）内容底稿

> 体例对齐 glycolysis/gk-04.md，压缩为 8 节。PDB 条目已于 2026-11-03 经 RCSB API（data.rcsb.org GraphQL + search API + chemcomp 化学字典）实时核验，表中分辨率/方法/配体/原子数均为当日查询结果。上代码前如隔数月，建议按糖酵解同款流程重核。

## 1. 反应式（11 步总览）

2 丙酮酸 + 4 ATP + 2 GTP + 2 NADH + 6 H₂O → 葡萄糖 + 4 ADP + 2 GDP + 6 Pi + 2 NAD⁺ + 2 H⁺（Lehninger Ch.20 净反应式，可追溯）。

七步与糖酵解共用同酶（PGI、醛缩酶、TPI、GAPDH、PGK、PGM、烯醇化酶）逆向运行；四个绕道反应替换糖酵解三个不可逆步：

| # | 绕道步 | 反应 | 酶 | 部位 |
|---|---|---|---|---|
| B1 | 丙酮酸羧化 | 丙酮酸 + HCO₃⁻ + ATP → 草酰乙酸 + ADP + Pi | 丙酮酸羧化酶 PC，EC 6.4.1.1 | 线粒体基质 |
| B2 | OAA 脱羧磷酸化 | 草酰乙酸 + GTP → PEP + GDP + CO₂ | PEP 羧激酶 PEPCK（人 PCK1 胞质 / PCK2 线粒体），EC 4.1.1.32 | 胞质（肝为主）/线粒体 |
| B3 | F1,6BP 水解 | 果糖-1,6-二磷酸 + H₂O → F6P + Pi | 果糖-1,6-二磷酸酶 FBPase-1（FBP1），EC 3.1.3.11 | 胞质 |
| B4 | G6P 水解 | G6P + H₂O → 葡萄糖 + Pi | 葡萄糖-6-磷酸酶 G6PC1（ER 膜蛋白），EC 3.1.3.9 | ER 腔侧（肝、肾、肠） |

B2 之前 OAA 必须离开线粒体：转苹果酸（苹果酸脱氢酶，顺带把 NADH 带入胞质供 B3 之后 GAPDH 反向用）或转天冬氨酸。原料三选一：乳酸（Cori，LDH 氧化时供胞质 NADH）、丙氨酸（葡萄糖-丙氨酸循环）、丙酮酸。

## 2. 酶与 EC（绕道四酶要点）

- **PC**（EC 6.4.1.1）：生物素依赖羧化酶，同源四聚体，每亚基含 BC（生物素羧化）域 + CT（羧基转移）域 + BCCP（生物素载体）域；乙酰-CoA 为别构激活剂（必需，无则几乎无活性）。生物素臂在两活性位点间摆动（~60 Å）。
- **PEPCK**（EC 4.1.1.32）：Mn²⁺ 依赖，GTP 驱动脱羧+磷酸化一步完成，把"不可逆"的 PK 逆向代价拆成一次脱羧放能 + 一次 GTP 水解。人有两同工酶：胞质 PCK1（肝）、线粒体 PCK2。
- **FBPase-1**（EC 3.1.3.11）：可溶四聚体，AMP 别构抑制位点（与 F6P 底物位点分离）；被 F2,6BP 抑制（与 PFK-1 的正调构成教科书级拔河）。
- **G6PC1**（EC 3.1.3.9）：多跨膜 ER 蛋白，活性位点朝 ER 腔；底物 G6P 经 SLC37A4（G6P 转运体）入腔，产物葡萄糖经 GLUT2 出肝。GSD-Ia/Ib 病灶即在此对搭档。

## 3. 热力学与 ΔG

- **总账**：糖酵解净产 2 ATP；糖异生耗 4 ATP + 2 GTP = 6 个高能磷酸键——"逆向跑通路要补 3 倍电力"是本通路第一教学锚点（Lehninger Ch.20，可追溯）。
- **PEP 的高能负债**：PK 正向把 PEP 的磷酸烯醇键（水解 ΔG°′ ≈ −61.9 kJ/mol，Lehninger 表 13 系）砸给 ATP；糖异生用 GTP 把这个键"买回来"。
- **逐步 ΔG 口径**：Lehninger Ch.20 详表数值本档案未逐字核实到唯一数字，**不冒充事实**；只作定性结论（有据）：B1/B4 强放能（ATP/GTP 或水解驱动），B2 放能（脱羧驱动），B3 放能（水解）。同酶反向七步在胞内均近平衡。禁止直接把 glycolysis.json 的 ΔG 取反当糖异生数据——PFK 的 −14.2 是 F6P+ATP→F1,6BP+ADP 的标准态，FBPase 走水解路径，两者不是同一条自由能曲线的正反两读。

## 4. 辅因子与化学计量

- PC：生物素（共价拴在 BCCP 的 Lys 上）、ATP、HCO₃⁻（碳源）；Mn²⁺/Mg²⁺。
- PEPCK：GTP、Mn²⁺（人体内首选二价阳离子存在 Mg²⁺/Mn²⁺ 之争，未核实唯一口径）。
- FBPase / G6PC：无辅因子（水解酶）；G6PC 需 ER 腔环境 + SLC37A4 转运。
- 同酶反向七步的净耗：2 NADH（供 GAPDH 反向把 1,3-BPG 还原到 G3P）。

## 5. 调控与生理意义

- **底物循环（futile cycle）叙事**：PFK-1 vs FBPase-1、PK vs (PC+PEPCK)、HK vs G6PC，三对"拔河"由 F2,6BP、AMP、乙酰-CoA、激素共同裁决。
- F2,6BP：正调 PFK-1、负调 FBPase-1——单一信使同时按住一个方向、松开另一个方向（教材共识）。
- 胰高血糖素/肾上腺素 → PKA → PFK-2/FBPase-2 双功能酶磷酸化 → F2,6BP↓ → 糖酵解↓糖异生↑；胰岛素反向。
- PC 的乙酰-CoA 别构激活：脂解旺盛时（乙酰-CoA 多）"告诉"丙酮酸去做糖而不是进 TCA——代谢分工的经典信号。
- 生理意义：空腹血糖维持（肝为主）、肾皮质在长期饥饿时贡献显著上升（比例数值教材出入大，未核实不写数）、乳酸/丙氨酸碳骨架回收。

## 6. 常见教学误解（3 条）

1. "糖异生是糖酵解倒着放"——三个不可逆步必须换酶绕道，代价是 4 ATP + 2 GTP；不分步换酶，热力学上根本走不通。
2. "肌糖原可以补血糖"——肌无 G6PC（也不表达 G6Pase 活性），肌肉糖原只能自己用；这是肝/肌糖原教学分工的根源。
3. "乙酰-CoA 激活 PC 所以被消耗"——乙酰-CoA 是别构激活剂，净不消耗；被消耗的是 ATP 和 HCO₃⁻。

## 7. 临床关联

- **GSD-Ia（von Gierke 病）**：G6PC1 缺乏，G6P 堆积→严重空腹低血糖、肝大、乳酸酸中毒、高尿酸（OMIM 232200）；**GSD-Ib**：SLC37A4 缺乏，同表型 + 中性粒细胞功能障碍（OMIM 232220）。
- **FBPase-1 缺乏**：空腹诱发低血糖 + 乳酸酸中毒（OMIM 232890）。
- **PC 缺乏**：罕见，乳酸酸中毒 + 低血糖 + 神经发育受损（OMIM 268650）。
- **PCK1 缺乏**：极罕见（OMIM 261650），临床表型报道有限（未核实）。
- 药物视角：FBPase 抑制剂（2Y5K 的 YCU 即磺酰脲类抑制剂）曾是 2 型糖尿病降糖药方向（临床转化状态未核实）。

**3D 四格（底物/apo/结合/产物）适配判断：**

- **FBPase-1**：最适合做帧带——结合态（1FTA 人 AMP 别构）、底物态（1EYI 猪 F6P，跨物种拼帧）、apo 帧缺人源 apo（未检索到，明说）；产物帧（F6P 态即近似）。能直接复用 gk-1 帧带的跨结构刚体对齐管线。
- **PEPCK**：结合态（1KHB GMPCP+Mn）质量高；OAA/PEP 真底物态人源未检索到（未核实→不写候选）；apo 帧缺。建议只做单帧 + 2D 机理图。
- **PC**：3BG3 丙酮酸+生物素同框很稀有（其他生物素酶少见双配体），但四聚体 ~2 万原子、双活性位点 + 摆动臂，单帧静态展示 OK，帧带意义有限（生物素臂运动是"过程"不是"四格"）。
- **G6PC1**：9J7U/9J7V 理论上凑齐"底物/apo"，但是多跨膜 ER 蛋白 + 3.1–3.3 Å cryo-EM + GFP 融合构建体，位点残基定位粗；**不建议上 3D 四格**，降级为 2D 机理示意 + 一张 9J7U 静态单帧（标注"2024 新结构、分辨率有限"）。
