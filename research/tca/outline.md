# TCA 循环 内容骨架（outline）

定位：糖酵解下游第二通路。本文只做内容骨架 + 3D 适配性判断，不做代码。所有 ΔG°′ 单位 kJ/mol，来源 Lehninger 8th ed. Table 16-2；个别教材间有 ±1–2 出入，未逐条跨教材核对处已注明。

## 连接步：丙酮酸脱氢酶复合体（PDH，单列）
丙酮酸 + CoA-SH + NAD⁺ →（TPP、硫辛酸、FAD、Mg²⁺）乙酰-CoA + CO₂ + NADH。三个酶组分 E1（EC 1.2.4.1，TPP）、E2（EC 2.3.1.12，硫辛酰赖氨酸摆臂）、E3（EC 1.8.1.4，FAD/NAD⁺）；戊糖磷酸相关的 E3 与支链 α-KG 脱氢酶共用机理（同型 E3）。受 PDH 激酶/磷酸酶共价调控（肝：产物乙酰-CoA/NADH 激活激酶；胰岛素激活磷酸酶——组织差异）。**接驳点本质**：糖酵解产丙酮酸，PDH 把丙酮酸变成 TCA 的唯一燃料入口；丙酮酸也可以经丙酮酸羧化酶走回补。
ΔG°′ ≈ −33.5（PDH）。适合 3D：E2 硫辛酰摆臂的"摆动传递"需要完整复合物结构（大肠杆菌 E2 核心 cryo-EM 有，哺乳动物复合体 cryo-EM 近年已解析，条目未核实）；E1/E2/E3 各自单独结构丰富。只能 2D：五步辅因子接力（TPP→硫辛酸→FAD→NAD⁺）作为示意图，理由——接力中间态无全捕获结构，硬约束"只展示实验结构可支撑的结合姿态"下不能画成 3D 流程。

## 8 步主链（底物→产物 / 酶 / EC / 辅因子 / ΔG°′）
1. 乙酰-CoA + 草酰乙酸 → 柠檬酸｜柠檬酸合酶｜EC 2.3.3.1｜无｜−32.2（强不可逆；受柠檬酸/琥珀酰-CoA 抑制）。
2. 柠檬酸 → 异柠檬酸（经顺乌头酸）｜乌头酸酶｜EC 4.2.1.3｜[4Fe-4S] 簇（脱水-再水合，不是简单异构）｜≈ +13.3（近平衡，教材差异大，未跨教材核实）。
3. 异柠檬酸 → α-酮戊二酸 + CO₂ + NADH｜异柠檬酸脱氢酶｜EC 1.1.1.41（NAD⁺ 型，线粒体基质）｜NAD⁺、Mg²⁺/Mn²⁺｜−20.9（不可逆；ADP 激活、ATP/NADH 抑制；限速步）。
4. α-酮戊二酸 + CoA → 琥珀酰-CoA + CO₂ + NADH｜α-KG 脱氢酶复合体｜EC 1.2.4.2 等｜TPP、硫辛酸、FAD、NAD⁺、Mg²⁺｜−33.5（不可逆；机理与 PDH 同型）。
5. 琥珀酰-CoA + GDP + Pi → 琥珀酸 + GTP + CoA｜琥珀酰-CoA 合成酶｜EC 6.2.1.4（ADP 型）/6.2.1.5（GDP 型）｜无外源辅因子｜≈ −2.9（近平衡；底物水平磷酸化，与糖酵解第 7/10 步同概念）。
6. 琥珀酸 + FAD → 富马酸 + FADH₂｜琥珀酸脱氢酶 = 呼吸链复合体 II｜EC 1.3.5.1｜FAD、[2Fe-2S]/[4Fe-4S]/[3Fe-4S]、泛醌｜≈ 0（近平衡；唯一嵌膜的 TCA 酶）。
7. 富马酸 → 苹果酸｜富马酸酶｜EC 4.2.1.2｜无｜−3.8（近平衡；立体专一反式加成）。
8. 苹果酸 + NAD⁺ → 草酰乙酸 + NADH｜苹果酸脱氢酶｜EC 1.1.1.37｜NAD⁺｜+29.7（**标准态强吸能**，靠第 1 步柠檬酸合酶大负 ΔG 拉动——与糖酵解第 4/5 步同款逻辑）。

## 与糖酵解的接驳点
入口 = 丙酮酸（经 PDH 或经丙酮酸羧化酶回补草酰乙酸）；NADH 交呼吸链（接 oxphos）；琥珀酰-CoA 与血红素合成相连；柠檬酸外运支撑脂肪酸合成。回补反应（anaplerosis）一段：丙酮酸羧化酶（EC 6.4.1.1，生物素，肝/肾，兼糖异生入口）；谷氨酸↔α-KG 转氨；天冬氨酸↔草酰乙酸；奇数碳脂肪酸氧化产琥珀酰-CoA。若无回补，TCA 中间体被合成反应抽走后循环流量衰减（"催化量使用中间体"概念）。

## 3D 适配性总判断
- 适合 3D（有实验结合姿态）：柠檬酸合酶（开放/闭合双态，配体齐）；乌头酸酶（Fe-S 簇+底物/抑制剂结构多）；琥珀酸脱氢酶/复合体 II（膜复合物结构成熟）；苹果酸脱氢酶、异柠檬酸脱氢酶（单酶单腔，与糖酵解 10 步同复杂度）。
- 只能 2D：整环 8 步总览（同理与糖酵解通路图）；PDH/E2 摆臂接力细节；Fe-S 簇电子传递路径（电子位置无结构证据）。
- 风险点：乌头酸酶活性依靠 [4Fe-4S] 中"第四个铁"结合底物羟基——配体姿态依赖金属簇，模型简化时不能丢；琥珀酸脱氢酶是跨膜复合物，3D 资产体积与"同屏 ≤2 大模型"约束冲突，建议单独成页。
