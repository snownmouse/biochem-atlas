# 糖酵解十步"结构状态"可得性核验（为单步页四格底账）

> 查询日期：2026-11-03。全部 PDB ID / 配体组成 / 分辨率 / 方法 / UniProt 映射来自当日 RCSB Search API + Data API (GraphQL) + UniProt REST 实时查询，逐 UniAcc 全条目扫描（每次检索行数上限 60）。查询脚本：`research/tmp-rcsb-query.mjs`、`tmp-rcsb-query2.mjs`、`tmp-rcsb-query3.mjs`（可重跑复核）。本文件不混入任何"未核实"条目；确属未核实的均显式标注。

## 结论（先行）

- **真四格：3 步** —— gk-2（PGI）、gk-9（烯醇化酶）、gk-10（丙酮酸激酶）。
- **三格：2 步** —— gk-1（己糖激酶，缺 apo）、gk-7（PGK，产物态无但有实验测得的过渡态模拟结构可作第四格替身）。
- **两格或更少：5 步** —— gk-3（PFK-1）、gk-4（醛缩酶）、gk-5（TPI）、gk-6（GAPDH）、gk-8（PGAM）。
- **最容易做样板的：gk-9**。3UCD（人 ENO2，1.41 Å X-ray）同一结构同时含底物 2PG、产物 PEP、双 Mg²⁺，是十步中唯一"底物+产物+金属"三件套同结构；apo 还能换成同酶同物种的 1TE6（人 ENO2，1.8 Å），做到四格全部"同人源同酶同编号体系"。
- **最重要的冲突事实**：甘油醛-3-磷酸与 1,3-BPG 在 PDB 化学组分字典中**不存在**（核查 GAP/GA3P/13B/13PG/23BPG/DPG/BPG 均非此分子或不存在）。gk-5、gk-6、gk-7 的产物格连小分子实验坐标都没有，只能 2D。

## 二、逐步说明

- 人 HK1 全部 10 个条目逐一核验，**无 apo**：1CZA(1.9)/1QHA(2.25)/1DGK(2.8)/1HKB(1HKC)(2.8)/4FP 系列(2.4–3.0) 全部带糖或核苷酸。

## 三、三个判据问题

### 1. 产物态来自另一结构/另一物种时，四格直接并置会误读吗？
会，分三档处理：
- **同一结构**（gk-1、gk-9）：直接并置，无对齐问题。
- **同酶同物种、跨结构**（gk-2 的 1U0F/2CXS；gk-10 的 6NN4/8TBS；gk-4 的 4ALD/5KY6；gk-7 全套）：残基编号一致、口袋拓扑一致，构象差异（开/合）是真实物理差异。可以并置，但必须标"**跨结构示意**"，且各格相机独立（现有 EmbeddedStepViewer 的切步保相机逻辑不能共用相机路径）。
- **跨物种/跨同工酶**（gk-5 1NEY 酵母、gk-8 1QHF 酵母、gk-2 的 apo 人 vs holo 鼠、gk-9 若沿用 2PSN）：口袋形状与编号体系都不同，直接并置**必然误读**。建议：3D 只放结合态一格里的人源/主图结构，apo 与异源态降为"2D 结构式 + 文字说明"；或者干脆该步不做四格、只做"结构状态可得性说明"。
- **原则：宁缺毋滥。不跨物种硬凑四格。**

### 2. 哪些是真四格？总表（见第一节表）
- **真四格 3 步**：gk-2（③④同酶同物种跨结构）、gk-9（两态同结构+同酶 apo）、gk-10（③④⑤可全 PKLR 同酶同物种）。
- **三格 2 步**：gk-1（无 apo；产物格有"抑制位点"语义折扣）、gk-7（产物格用 MgF₃ 过渡态替身）。
- **两格或更少 5 步**：gk-3（底物+无 apo）、gk-4（底物+apo）、gk-5（底物+apo）、gk-6（辅因子+apo，底物级全无）、gk-8（底物+apo）。

### 3. 无产物态的步骤，用 RDKit ETKDG 计算构象是否唯一路径？
**不是，且多数情况不该用。** 分三种情形：
- **分子本身有实验坐标、只是没有"酶+产物"复合物**（gk-3 的 FBP、gk-4 的 DHAP、gk-8 的 2PG）：直接取 PDB 组分/其他复合物中的实验坐标（标注来源结构），比 RDKit 生成更诚实、零计算。RDKit 唯一的应用场景是"产物游离构象展示"，但这里根本不需要。
- **分子本身无实验坐标**（gk-5/gk-6 的甘油醛-3-磷酸、gk-6/gk-7 的 1,3-BPG）：这是**化学组分字典层面缺失**，RDKit 生成 3D 构象反而是唯一能出 3D 的办法——但正因为它无实验对照，立体化学与构象完全靠计算，建议**只用 2D 结构式**（反应中心局部示意 + 立体化学标注），比"计算构象 3D 球棍"更诚实。
- **"酶+产物口袋"场景**：把计算构象摆进 apo 口袋 = 编造结合模式（口袋形状由结合态诱导，apo 口袋放计算构象是伪科学）。**禁止**。
- **gk-7 特例**：2WZB 的 MgF₃ 过渡态模拟是真实实验坐标且含产物侧 ADP——"第四格 = 过渡态模拟（实验坐标）"远优于任何计算构象。

## 四、与"四格"设想冲突的结构事实（汇总）

1. **甘油醛-3-磷酸、1,3-BPG 不存在于 PDB 组分字典**（GAP=甘氨酰腺苷-5'-磷酸；G3P=sn-甘油-3-磷酸；GA3P/13B/13PG/23BPG 不存在；DPG/BPG 均为无关分子；2,3-BPG 的代码是 DG2）。gk-5/6/7 的产物格与 gk-5/6 的底物格连小分子坐标都没有。
2. **9FFC（人 TPI 1.25 Å）中的 G3P 是 sn-甘油-3-磷酸**，不是甘油醛-3-磷酸——分辨率最高的人 TPI 结构反而是个陷阱。
3. **方向口径**：2CXS 的 F6P 按糖酵解方向是产物；asset-audit/manifest 里 role=substrate 的标注需按展示方向修正或加注。
4. **1CZA 的 G6P 在抑制位点**，非活性位点产物位；"同结构含产物"的语义要写清。1QHA（2.25 Å，含 ANP+Mg）是含 ATP 类似物的替代 static。
5. **6NN4 无 ADP**——gk-10 结合态缺核苷酸侧底物。
6. **8TBS 系产物态用 Mn²⁺ 替代 Mg²⁺ 且共存筛选片段**（HVI 等）——用于产物格需双 caveat。
7. **3UCD 的 2PG 与 PEP 分处不同亚基**（A/B 链）——"两态同结构"≠"同口袋两态"。
8. **PGAM 全系无 2PG/DG2 结构**（人 33 条+酵母 6 条逐一核验）——gk-8 连引物态都没有。
9. **8W2H（T 态）含 ATP+FBP 但 FBP 位点身份未核实**——gk-3 不可声称产物态。
10. **UniAcc 备忘**：PFKL=P17858（非 P17861，后者是 XBP1）、PFKM=P08237、PKLR=P30613（非 P30685）——后续脚本按 UniAcc 检索时用错会静默返回空。
11. **apo 升级机会两处**：gk-9 可用 1TE6（ENO2 同酶）替换 2PSN；gk-10 可用 6NN5（PKL 同酶）替换 1ZJH（PKM）。gk-6 的 8G17 实查为 EM 而非 X-ray，作 apo 时需标方法。

## 五、给单步页设计的结论

- **可以先做真四格**：gk-9（样板首选：3UCD 两态同结构 1.41 Å 人源 + 1TE6 同酶 apo，四格同人源同酶同编号）→ gk-10（6NN4 + 8TBS + 6NN5 全 PKLR；caveat=Mn²⁺/片段/无 ADP）→ gk-2（1U0F + 2CXS 同酶同物种跨结构；apo 人源跨物种，需标）。
- **只能做三格**：gk-1（底物/产物同结构 + 无 apo；建议把"无 apo"本身做成一格文案，HK1 的别构闭合仍有教学价值）、gk-7（9FDN + 8YHP + 2WZB 过渡态替身，四格凑齐但第四格标"过渡态模拟"）。
- **建议两格 + 2D**：gk-3（F6P/FBP 游离构象用 8W2G/4ALD 实验坐标，产物态 2D）、gk-4（4ALD + 5KY6，产物双分子 2D 结构式）、gk-8（1QHF + 4GPZ，产物态与引物态 2D）、gk-5（1NEY 酵母 + 2JK2 人 apo，产物 2D；PGA 类似物可作"中间体示意"补偿证据）、gk-6（1U8F + 8G15，底物/产物全部 2D——这是十步中唯一"结构上几乎无话可说"的步骤，2D 反而最诚实）。
- **通用纪律**：四格并置仅在"同结构"或"同酶同物种跨结构"时允许 3D；跨物种一律降级为 2D + 文字；所有替身（MgF₃/ANP/OXL/PGA/2FP 线形）在格内显著标注身份；实验坐标缺失的分子不生成计算 3D。
