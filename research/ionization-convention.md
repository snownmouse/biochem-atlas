# 全站代谢物电离态口径（生理 pH 7.4）

本文件是 `src/data/comparisonConfig.ts`、`src/data/*.json` 与 `public/assets/ligands3d|structures/2d/*`
的**唯一分子式口径**。规则由 `tools/validate-ionization.mjs` 机械复核；资产重电离由
`tools/reionize-assets.py` 执行（只改电荷/氢数，不改重原子坐标）。

## 1. 规则表

| 官能团 | 7.4 下的形态 | 每个基团的净电荷 | 依据（常见 pKa） | 本项目实例 |
| --- | --- | --- | --- | --- |
| 磷酸单酯 R–O–PO₃²⁻ | 二价阴离子（两个端基 O 均去质子） | −2 | pKa1 ≈ 1–2，pKa2 ≈ 6.3–7.2（G6P 约 6.1） | G6P、F6P、DHAP、GAP、3PG、2PG、6PG、6PGL、Ru5P、R5P、Xu5P、S7P、E4P、FBP 的两个磷酸、1,3-BPG 的 C3 磷酸 |
| 磷酸二酯 R–O–PO₂⁻–O–R′ | 本项目中无独立代谢物；不套用单酯规则 | 按端基 O 逐个计 | 二酯的端基 O pKa 约 1–2，通常 −1 | （仅 CoA 的 5′-二磷酸酐涉及，见 §3.6） |
| 酰基磷酸（混酐）R–C(=O)–O–PO₃²⁻ | 二价阴离子（酰基磷酸是强酸） | −2 | 酰基磷酸 pKa ≈ 3.5–4.5，7.4 下两个质子均已离去 | 1,3-BPG 的 C1 磷酸 |
| 烯醇磷酸 R–C=C–O–PO₃²⁻ | 按磷酸单酯，二价阴离子 | −2（另加羧酸 −1） | 同磷酸单酯 pKa2 ≈ 6.3 | PEP（C3H2O6P，净 −3） |
| 羧酸 R–CO₂H | 一价阴离子 R–CO₂⁻ | −1 | pKa ≈ 4.8（TCA 有机酸 3.0–5.0） | 丙酮酸、乳酸、OAA、柠檬酸/异柠檬酸（各 3 个）、α-KG、琥珀酸、富马酸、苹果酸、6PG、3PG/2PG、PEP、棕榈酸、谷氨酸的 2 个羧基 |
| 硫酯 R–C(=O)–S–R′ | 不电离（S 上无质子；α-C–H pKa 13–16，7.4 下不去质子） | 0 | 硫酯 pKa > 13 | 乙酰-CoA、琥珀酰-CoA、脂酰-CoA 的硫酯键 |
| 氨基（氨基酸 α-NH₂/NH₃⁺） | 质子化为 NH₃⁺；与羧酸根配对后净电荷再判 | +1（每个 α-氨基） | α-NH₃⁺ pKa ≈ 9.0–9.7，7.4 下以 NH₃⁺ 为主 | 谷氨酸、丙氨酸 |
| 季铵 / 肉碱 | 已带正电，不再质子化 | +1 | 永久电荷 | 肉碱、酰基肉碱 |
| 醇 / 酚 / 酮 / 醛 / 内酯 | 不电离 | 0 | 醇 pKa 15–17，酚 ≈ 10 | 糖环羟基、6PGL 内酯、DHAP/GAP 的羰基 |
| 碳酸氢根 / CO₂ | HCO₃⁻ / CO₂ | −1 / 0 | H₂CO₃ pKa1 ≈ 6.35 | 糖异生/PPP 的 HCO₃⁻、CO₂ |

**记账方式**：分子式 H 数 = 中性（全质子化）分子式的 H 数 − 该分子在 7.4 下实际离去的质子数；
净电荷 = 各官能团电荷之和。例：G6P 中性 C₆H₁₃O₉P，磷酸二价阴离子去 2 H → **C₆H₁₁O₉P，净 −2**。

## 2. 特殊判定（不套用单酯规则的地方）

### 2.1 1,3-BPG 的 C1 酰基磷酸
C1 是 `R–C(=O)–O–P` 的混酐，不是普通磷酸酯：磷酸的两个端基 O 都接在 P 上，pKa 很低
（≈3.5–4.5），7.4 下两个质子均已离去，因此 **C1 磷酸按 −2**；C3 是普通磷酸单酯，也按 −2。
整分子 **C₃H₄O₁₀P₂，净 −4**。高能键是热力学性质，不是另一种键型，2D 仍画普通 C–O–P 单键。

### 2.2 PEP 的烯醇磷酸
PEP 的磷酸接在 C2 烯醇氧上，是磷酸单酯 → −2；C1 羧酸 → −1。整分子 **C₃H₂O₆P，净 −3**。
烯醇式与酮式（丙酮酸）不是同一分子，不能互相套用。

### 2.3 硫酯
酰基-CoA 的 `C(=O)–S–CoA` 在 7.4 下不电离，硫酯片段净电荷只来自同一片段内的羧酸（如琥珀酰-CoA
的 C4 羧酸 −1）。因此乙酰-CoA 片段 C₃H₆OS 净 0，琥珀酰-CoA 片段 C₅H₇O₃S 净 −1。

### 2.4 CoA 的 3′-磷酸
CoA 的 3′-磷酸是磷酸单酯 → −2。完整 CoA 分子式（只作块级来源注记，页面从不整分子入画）按
“中性式 −2 H”计：乙酰-CoA C₂₃H₃₆N₇O₁₇P₃S、棕榈酰-CoA C₃₇H₆₄N₇O₁₇P₃S。**5′-二磷酸酐不在此口径内**：
它是磷酸酐，7.4 下的质子化程度在 2–3 之间浮动，且页面只画反应端片段；为避免把未观测到的形态写成
确定值，完整式只计 3′-磷酸，并在 caveat 中注明“泛酸/腺苷部分不入画”。这是**有意保留的差异**，不是漏改。

### 2.5 氨基酸：谷氨酸 vs 丙氨酸
- 谷氨酸：α-COOH −1、侧链 γ-COOH −1（pKa 4.25）、α-NH₃⁺ +1 → **C₅H₈NO₄，净 −1**。
- 丙氨酸：只有 α-COOH 与 α-NH₂；中性式 C₃H₇NO₂ 与两性离子式（COO⁻/NH₃⁺）**分子式完全相同**，
  净电荷都为 0。本项目 2D 资产沿用中性式（不带电荷圈），口径选择是“净 0 即可，不为画电荷而改画”。

### 2.6 肉碱 / 酰基肉碱
肉碱是季铵 + 羧酸根的 zwitterion（净 0）；酰基化只改羟基，不改电荷。资产保持 +1/−1 两个电荷标记，
分子式不变。

### 2.7 6PGL 内酯
内酯环上的 C1=O 不是羧酸（单键 O 在环内、还有另一个重原子邻居），**不产生羧酸根**；只有 C6 磷酸
按单酯 −2。故 6PGL = **C₆H₉O₉P，净 −2**，不是 C₆H₁₁O₉P。

### 2.8 碳酸氢根 / CO₂
HCO₃⁻ 净 −1（C 上两个 O 双键、一个 O⁻ 单键、一个 OH）；CO₂ 净 0。两者只做 2D，无 3D 资产。

## 3. 生理 pH 下仍存在多种形态的分子（口径选择与理由）

| 分子 | 7.4 下的多种形态 | 本项目选哪种 | 理由 |
| --- | --- | --- | --- |
| G6P | α/β 吡喃异头体；开链极少 | 保留实验配体/2D 资产的环型 | 异头体不改变分子式与电荷，只影响 2D 立体标注与 3D 形状 |
| F6P | 呋喃环 / 吡喃环 / 开链 | 2CXS 晶体的呋喃型 | 实验坐标决定形状；分子式 C₆H₁₁O₉P 不变 |
| FBP | 呋喃型（自由态）/ 线形（醛缩酶结合态） | 两个资产分开呈现，不混标 | 两种实验构象；分子式同为 C₆H₁₀O₁₂P₂ |
| OAA | 酮式 / 烯醇式 | 8ZVW 实测的酮式 | 7.4 下酮式为主；两种形式分子式相同 |
| 丙氨酸 | 中性式 / 两性离子 | 中性式（净 0） | 分子式相同；不为统一而强行加电荷圈 |
| CoA 5′-二磷酸酐 | 质子化程度 2–3 浮动 | 完整式只计 3′-磷酸 −2 | 页面只画片段；避免把浮动形态写成定值（见 §2.4） |
| 1,3-BPG | 酰基磷酸极不稳定，可水解 | 按完整分子计 −4 | 展示的是反应瞬态；水解产物是 3PG，不是同一分子 |
| 乳酸 / 丙酮酸 | 羧酸根为主；少量质子化 | 一价阴离子 | pKa 3.86 / 2.5，7.4 下几乎完全去质子 |

**不统一的地方**：完整 CoA 式与片段式同时存在（块级注记 vs 实际入画），以及丙氨酸中性式。原因如上，
属有意保留；除这两处外，同一分子的分子式字符串在全站完全一致。

## 4. 机械执行

1. `tools/reionize-assets.py`
   - 从现有 3D 资产的原子/键表重建分子（**不重新嵌入坐标**），按结构置形式电荷：
     P 上无碳邻居的单键端基 O → −1；同时有 C=O 与“无其他重原子邻居的单键 O”的碳 → 该 O −1；
     谷氨酸 α-N（度为 1）→ +1。
   - 再用 RDKit `AddHs(addCoords=True)` 补氢，重算 `formula / smiles / molecularWeight / shape`；
     `shape` 只随氢数变化，重原子坐标逐位不变。
   - 2D 资产从同一 SMILES 用 RDKit 重画（含电荷），与 3D 的电荷/重原子一致。
2. `tools/validate-ionization.mjs`
   - 规则表自检：每条规则必须写明电荷与 pKa 依据；
   - 从资产的原子/键/电荷**独立推算**分子式（C4、N3/N+4、O2/O−1、P5、S2 的隐式氢规则），
     与资产自带 `formula`、数据层 `formula` 三方比对；
   - 跨通路一致性：按实体映射（g6p↔g6p-g6pd、f6p↔f6p-gn、fbp↔fbp-linear↔fbp-gn、
     pyr↔pyr-gn、6pg↔6pg-l、ru5p↔ru5p-i）比对同一分子的分子式字符串；
   - 2D/3D 资产一致性：重原子元素计数、净电荷、键级计数；
   - 输出“分子 × 通路”全量对照表。

## 5. 资产与页面影响

- 3D 资产只存重原子坐标；补氢只改 `formula/charge/shape`，坐标不变。
- 体积按补氢后的范德华球计算，因此数字变化；默认 2D/3D 判据
  （重原子数不变 + 拓扑改变 + |ΔV| ≤ 2.5% → 2D）随之复核：
  - **ppp-o1 由 2D 翻为 3D**（−1.90% → −3.13%，越过阈值）；
  - **ppp-n5 由 3D 翻为 2D**（−2.81% → −1.35%，回到阈值内）；
  - 其余块默认模式不变（逐块数字见 `comparisonConfig.ts` 的 `defaultModeRule`）。
- 页面只读数据层的 `formula` 与 `defaultModeRule`，不写死分子式；本轮未新增任何视觉元素。
